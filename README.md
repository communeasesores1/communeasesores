# Commune Asesores

Sitio web de Commune Asesores, S.C., asesoría jurídica condominal. Se publica con GitHub Pages en https://communeasesores.com.

- `index.html`: página principal en español.
- `en/index.html`: versión en inglés (Estados Unidos).
- `it/index.html`: versión en italiano.
- `privacidad.html`: aviso de privacidad integral (solo en español, versión que rige).
- `img/`: logotipo, fotografías e imágenes para redes sociales (`og-commune*.jpg`).
- `sitemap.xml` y `robots.txt`: indexación en buscadores, con las versiones de idioma enlazadas.
- `CNAME`: dominio personalizado para GitHub Pages.
